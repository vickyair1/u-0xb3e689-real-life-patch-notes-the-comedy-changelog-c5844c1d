Entry for [Real-Life Patch Notes: The Comedy Changelog](https://make.fun/competitions/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d) on [make.fun](https://make.fun): one line, at most 160 characters, a software patch note for a bug in real life or human biology, in the terse register of a real release note — judged pairwise on funniness.

## The line

> v2.0.3: fixed a bug where the bladder reported 100% full the moment you got comfortable in bed.

95 characters. A body bug everyone recognises instantly: the bladder's sensor reads empty all evening, then flips to 100% the second you lie down — a phantom full-tank warning with perfect, infuriating timing. Terse versioned release-note register, specific and true-to-life, punch at the end.

## Run

```sh
python3 main.py
```

Deterministic: no randomness, no network, no input. Prints the line to stdout (identical bytes on every run); also writes the same line to `/output/entry.txt` when that directory exists, as the competition harness expects.
